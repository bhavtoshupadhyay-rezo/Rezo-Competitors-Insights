## 🎨 Color Legend

### Category Badges
- 🟣 **Purple** - Voice Bot Specialist
- 🔵 **Blue** - Speech Analytics
- 🟢 **Green** - Omni Channel CX
- 🟠 **Orange** - Contact Center Tech
- 🩷 **Pink** - Core Tech & Models

### Status Indicators
- ✅ **Green** - Has feature / Success / Positive
- ❌ **Red** - Missing feature / Gap / Threat
- ⚠️ **Yellow** - Warning / New / Attention needed
- 🔵 **Blue** - Information / Neutral

### Buzz Score Colors
- 🟢 **80-100** - Hot (Green)
- 🔵 **60-79** - Moderate (Blue)
- 🟡 **0-59** - Emerging (Yellow)

## 🎯 User Flows

### Flow 1: Exploring a Competitor
```
Dashboard → Click Company Card → View Details →
Click "Compare with Rezo.ai" → See Feature Gaps →
Understand Competitive Advantage
```

### Flow 2: Discovering New Entrants
```
Dashboard → Click "Scan New" → Watch Progress →
Review New Companies → Check Match Scores →
Add High-Match to Watchlist → Get Alerts
```

### Flow 3: Checking Market Updates
```
Dashboard → Click Bell Icon → Filter by Type →
Read Notification → Click "View Details" →
Open Company Profile → Take Action
```

### Flow 4: Comparing Multiple Competitors
```
Dashboard → Click "Compare" → Select Competitor →
Review Feature Table → Note Gaps →
Switch to Different Competitor → Compare Again
```

## 📱 Responsive Behavior

### Desktop (>1024px)
- 3-column company grid
- Side-by-side comparison table
- Full-width modals with sidebars

### Tablet (768px - 1024px)
- 2-column company grid
- Stacked comparison sections
- Full-screen modals

### Mobile (<768px)
- 1-column company grid
- Vertical comparison layout
- Full-screen modals with scrolling

## ⌨️ Keyboard Shortcuts (Suggested)

- `Cmd/Ctrl + K` - Focus search
- `Cmd/Ctrl + N` - Open notifications
- `Cmd/Ctrl + S` - Open scanner
- `Cmd/Ctrl + C` - Open comparison
- `Esc` - Close modal
- `Tab` - Navigate between elements

## 🔄 Loading States

All components include smooth loading animations:
- Fade-in for cards and modals
- Progress bars for scanning
- Skeleton screens for data loading
- Spinning icons for active processes
